把 ~/Documents/SA/data/ 下的 *.csv 合成一份月度报表。

要做什么：
1. 列出该目录下所有 csv，逐个读表头，确认列名和行数；读不了的文件（编码不对、缺列、空文件）在报告里点名，不要跳过。
2. 用 python3 或 awk 做下面的统计，脚本本身也留在本目录里（scripts/ 下），方便我复核：
   - 每个文件的行数、时间跨度（最早与最晚的日期列）
   - 按月汇总的关键指标：如果存在名为 amount / value / count 之一的数值列，就按月求和与均值；没有就在报告里说明该文件无法汇总
   - 缺失值与重复行的数量，按文件分别给出
3. 产出两个文件：
   - report.md：结论在前（三到五条），然后是方法、每个文件一节的数据、以及「数据质量问题」一节
   - charts/：如果 matplotlib 可用，画月度趋势图（每个可汇总的指标一张 png）；不可用就在 report.md 里说明，不要用别的方式凑图

怎样算做完：report.md 和 scripts/ 都在本目录里，然后用 myagent_report 汇报 state=ready，summary 用三句话说明处理了几个文件、最重要的一个结论、以及有没有数据质量问题，files 列出 report.md 和 charts/ 下的文件。

源目录不存在或一个 csv 都没有时，汇报 state=dropped，summary 说明目录路径和它当时是空的。
需要我确认口径时（例如两个文件的同名指标定义明显不同、不知道该不该合并）汇报 state=blocked，question 写清楚两种口径分别会得出什么，以及你建议选哪个。
